# Internationalization (next-intl)

English is the official language of the LevelUp ecosystem; French is a translation.
The dashboard uses [next-intl](https://next-intl.dev) (App Router) **without locale
prefixes in the URLs**: `/dashboard/site` is the same route in every language.

## How the locale is chosen

`src/i18n/request.ts` (registered in `next.config.ts` with `createNextIntlPlugin`):

1. the `NEXT_LOCALE` cookie (`en` or `fr`);
2. otherwise the browser's `Accept-Language` header (best of `en` / `fr`);
3. otherwise English (`defaultLocale` in `src/i18n/config.ts`).

Signed-in users also have `user_metadata.locale`. When a browser has no cookie yet, the
proxy (`src/lib/supabase/proxy.ts`) copies the saved locale into the cookie, so the
choice follows the account across devices.

The language switcher (`src/components/i18n/locale-switcher.tsx`) is in the user menu
(`LocaleMenuSub`) and at the bottom of every auth card (`LocaleSwitcher`). It calls the
server action `setLocale()` (`src/i18n/actions.ts`): cookie for one year, plus
`user_metadata.locale` when signed in. Sign-up and onboarding also save the locale in use.

Dates and numbers: use `useFormatter()` / `getFormatter()` (time zone
`America/Toronto`, `src/i18n/config.ts`), never `toLocaleString('fr-FR')`.

## Messages

- `messages/en.json` (source of truth, typed) and `messages/fr.json`. Both must have the
  same keys.
- Keys are grouped by area: `common`, `nav`, `auth.*`, `site.*`, `profile`, `team`,
  `errors`, `validation`, `setup`, `assistant`, `emails`, `metadata`, `admin`.
- `src/i18n/global.d.ts` types the keys from `en.json`: a typo or a missing key fails
  `tsc`.
- Format is ICU: `{name}`, `{count, plural, one {# call} other {# calls}}`, rich text with
  tags (`"Email us at <email></email>."` + `t.rich('key', { email: () => <a …/> })`).
  Use typographic apostrophes (`’`): an ASCII `'` is an ICU escape character. Literal
  braces must be passed as variables (see `site.seo.pagesHint`).

### What reaches the browser

The root layout passes `clientMessages()` (`src/i18n/client-messages.ts`) to
`NextIntlClientProvider`: everything except `metadata`, `emails`, `api` and `admin`.
LevelUp staff screens (`/dashboard/exclusive`) wrap their content in their own provider
with the `admin` messages, so the wording of internal tools never ships to client accounts.

## Adding strings

1. Add the key to `messages/en.json` **and** `messages/fr.json` (natural, professional
   English first; French is a translation, not the other way round).
2. Use it:
   - Server component / `generateMetadata` / route handler:
     `const t = await getTranslations('area');`
   - Client component: `const t = useTranslations('area');`
   - Outside a request (e-mails to someone else): `getTranslatorFor(locale)` from
     `src/i18n/messages.ts`.
3. Page metadata: `export async function generateMetadata()` with `getTranslations`, never
   a hard-coded `metadata.title`.
4. Navigation: `title` / `label` in `src/config/nav-config.ts` are keys of `nav.items` /
   `nav.groups`.
5. Zod schemas with messages are built inside the component
   (`useMemo(() => z.object({ email: z.string().email({ message: tv('email') }) }), [tv])`
   with `tv = useTranslations('validation')`).
6. Errors: services throw `new AppError('code')` (`src/lib/errors.ts`, codes = keys of
   `errors`), components show `useErrorMessage()(error)`. Never put a raw database or
   provider message in a toast.
7. Run `npx tsc --noEmit` (key check) and `npm run lint`.

## E-mails

- Auth e-mails (Send Email Hook, `src/lib/email/auth-emails.ts`): the recipient's
  `user_metadata.locale`, English when unknown.
- Access decision e-mails (`/api/access/decision`): the applicant's locale, returned by
  `review_access_request` (migration `20261009100000_review_access_request_locale.sql`),
  English when unknown.
- Internal notices to the LevelUp team: always English.

## Not translated

The template demo pages (products, users, kanban, chat, AI chat demo, forms showcase,
React Query, icons) keep their English demo content; only their navigation labels are
translated.
